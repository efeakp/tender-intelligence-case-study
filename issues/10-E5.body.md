## User story

As IT, we want the tool to run from company systems with no secrets in code, so that it is secure and supportable.

## Acceptance criteria

- [x] Code is in the company GitHub organisation
- [x] No credentials appear in the repository or its history
- [x] A README explains how to run and support it
- [x] Portal accounts use a shared team mailbox

- **Epic:** E5 Operations and handover
- **Priority:** Must
- **Requirements:** N2, N3, N4
- **Status:** Delivered
