## User story

As a director, I want an AI summary of a tender and CSV exports, so that I can make quick go/no-go calls and report in Power BI.

## Acceptance criteria

- [x] A structured summary can be generated for any tender
- [x] Tenders and the shortlist can be exported as CSV
- [x] Exports respect the same filters as the dashboard
