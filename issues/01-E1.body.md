## User story

As a bid coordinator, I want notices from all UK procurement portals in one place, so that I don't search each portal separately.

## Acceptance criteria

- [x] Notices from Find a Tender, Contracts Finder, Sell2Wales and Public Contracts Scotland appear in one list
- [x] Duplicates across portals are merged into one record
- [x] A failed source shows an error instead of silently missing data

## Details

- **Epic:** E1 Data ingestion
- **Priority:** Must
- **Requirements:** F1
- **Status:** Delivered
