## User story

As a bid coordinator, I want to filter tenders by keyword, region, CPV code, source, score and deadline, so that I can find the right ones quickly.

## Acceptance criteria

- [x] All listed filters can be combined
- [x] Results can be sorted by score, deadline, published date or value
- [x] Results are paginated
