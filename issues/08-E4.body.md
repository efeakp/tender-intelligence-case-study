## User story

As the Commercial Director, I want to record bid decisions and outcomes, so that we can report win rates and learn from losses.

## Acceptance criteria

- [x] A tender can be shortlisted with decision, confidence and notes
- [x] Outcome can be set to bid, won, lost or no-bid
- [x] The winner of a lost tender can be looked up
- [x] Users can rate how accurate the relevance score was
